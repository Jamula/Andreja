User directive: "Team, when there are changes in the branch, create a PR at the earliest convinience". Open a draft PR at the earliest practical point once scoped branch changes can be committed/pushed; update the same PR as work progresses. Follow repository templates and review gates. Early PR creation does not authorize merging, deployment or spending.
