User directive: "when the PR has active feedback, take the time to review the feedback and work through it; if you dont plan to accept the fix, add a comment and resolve it; try to work autonomously; try to remain unblocked and make forward progress; be proactive as much as possible". Review feedback carefully; implement accepted scoped fixes and validate; if declining, explain the reason in the existing review thread and resolve once addressed, without concealing genuine unresolved blockers. Progress autonomously within authorized scope, preserving reviewer rejection lockouts and explicit human/privacy/security/cost/deployment/merge gates. Escalate only decisions requiring user authority.
